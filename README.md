# ГИБДД-Очевидец

Android-приложение очевидца для анонимной отправки сообщений сотрудникам ГИБДД. Приложение предоставляет единый чат для отправки текстовых сообщений, фотографий и данных о местоположении.

## Стек

- Kotlin, Android Views и XML;
- Retrofit, OkHttp, Gson;
- Kotlin Coroutines;
- Android Keystore;
- Camera API и MediaStore;
- Photo Picker;
- OpenFreeMap;
- Android Location API;
- minSdk 26 (Android 8.0).

## Реализовано

 - приветственный экран и единый непрерывный чат;
 - анонимная регистрация устройства по SHA-256 fingerprint;
 - сохранение device_id и обновление access_token;
 - защищённое хранение данных сессии через Android Keystore;
 - отправка и получение текстовых сообщений;
 - выбор фотографий и видео через галерею и Photo Picker;
 - отправка фотографий и видео на backend;
 - отображение фотографий и видео в истории чата;
 - кэширование загруженных изображений;
 - полноэкранный просмотр фотографий;
 - отображение сообщений с группировкой по дням;
 - отображение локального времени сообщений;
 - статусы отправленных сообщений: одна и две галочки;
 - обновление статуса доставки через WebSocket;
 - отправка текущего местоположения;
 - выбор статической точки на OpenFree Картах;
 - live-геолокация с интервалом 1 секунда;
 - ручная остановка live-геолокации;
 - отображение live-трансляции в чате с кнопкой остановки;
 - обновление истории чата через периодические запросы к backend;
 - WebSocket для реального времени;
 - экран бана для Очевидца;
 - отображение бана и даты окончания;
 - таймер обратного отсчёта до окончания бана;
 - очистка чата после окончания бана;
 - push-уведомления о снятии бана;
 - интеграция Firebase Cloud Messaging;
 - получение и передача FCM-токена на сервер;
 - обработка входящих push-уведомлений;
 - контекстные кнопки после первого текстового сообщения;
 - плавная прокрутка чата;
 - диалог повторной отправки при ошибке соединения;
 - обработка системных отступов (WindowInsets);
 - кастомный PopupWindow для выбора медиа и геолокации;
 - чекбокс «Больше не показывать» на приветственном экране

## Backend

Приложение взаимодействует с backend через REST API.

Подключены:

- регистрация устройства;
- получение истории чата;
- отправка текстовых сообщений;
- загрузка медиа;
- отправка статической геолокации;
- отправка live-геолокации;
- получение статусов доставки сообщений.
- получение бана.

  
## Структура
- ChatActivity — основной экран чата, сообщения, медиа, камера и геолокация;
- network — работа с REST API и ApiRepository;
- data — модели данных и управление сессией;
- SessionManager — хранение данных авторизации;
- DeviceFingerprint — формирование идентификатора устройства;
- res/layout — XML-разметка экранов;
- res/drawable — графические элементы и фоны;
- AndroidManifest.xml — разрешения и компоненты приложения.
## Ещё не реализовано
- fallback для ANDROID_ID (генерация UUID, если ID недоступен)
- защищённое хранение для UUID (можно через EncryptedSharedPreferences)
- проверка размера – фото ≤10 МБ, видео/GIF ≤100 МБ
- Офлайн-сохранение и кнопка повторной отправки
- полноценная offline-очередь сообщений
- автоматический retry неотправленных сообщений при восстановлении соединения.
